Диагностика запуска PeerFerry

1. Распакуйте эту папку целиком.
2. Запустите PeerFerry-Diagnostics.cmd обычным двойным щелчком. Права администратора не требуются.
3. Если программа не установлена, выберите PeerFerry.exe из распакованной portable-папки.
4. Подождите завершения проверки. Пробный запуск длится до 30 секунд, затем собираются системные события.
5. Рядом появится PeerFerry-Diagnostics-ДАТА.zip. Передайте его для разбора ошибки.

Проверка работает в отдельном временном профиле и не требует установки .NET.
Она может ненадолго показать тестовые окна PeerFerry и закрыть их.
Собираются версия Windows/процессора, список файлов программы, код завершения,
ошибки загрузки .NET и события с упоминанием PeerFerry.
Настройки группы, ключи, сертификаты, приглашения и пользовательские файлы в отчёт не добавляются.
