# PeerFerry 0.2.2 — 6 ноября 2026

Причина раннего завершения 0.2.1 подтверждена полученным отчётом: Windows 10 Pro 20H2 x64 (19042.1526), CoreCLR 10.0.14, код `0x80131506`, сообщение `Your Windows doesn't fully support CET`. Сбой происходит до выполнения `Main`; обработчик исключений WPF не может его перехватить. Исходный отчёт содержит сведения чужого компьютера и в репозиторий не добавляется.

В проекте приложения установлен `CETCompat=false`. Это документированный Microsoft способ убрать автоматическое включение CET для данного EXE; системные настройки защиты не меняются. Аппаратная защита теневого стека для процесса PeerFerry больше не запрашивается, в том числе на новых Windows. ASLR/DEP остаются включены.

Проверено локально на Windows 11:

- Все 15 тестов ядра прошли.
- Проверка PE-заголовка обнаруживает CET в старом опубликованном EXE 0.2.1 и отклоняет его. Новый EXE 0.2.2, включая `current/PeerFerry.exe` внутри portable-пакета, проходит проверку: CET-флаг выключен, ASLR/DEP включены. SHA-256 упакованного EXE совпадает с проверенным publish.
- Встроенная проверка интерфейса из готового portable-пакета прошла: публикация, предпросмотр, скачивание с двух узлов, пауза/продолжение, выбор строк, фильтры, компактное окно и настройки. Использовался отдельный профиль.
- Сборщик диагностики прошёл проверку в Windows PowerShell 5.1. Данные приложения и события Application сохраняются в разные файлы.
- Установщик проверен с четырьмя комбинациями ярлыков. Проверены их цели/иконки, реальное обновление 0.2.2 → 0.2.3 с перезапуском и сохранением выбора ярлыков, штатное удаление. Использовался отдельный ID `PeerFerryInstallerTest`.
- Изолированная portable-копия опубликованной 0.2.1 обновилась из подготовленного локального feed до 0.2.2 и перезапустилась. Версия сборки после перезапуска — 0.2.2.0; новый EXE проходит проверку CET, его SHA-256 совпадает с новым publish.

Сборка включает .NET 10.0.14 и Desktop Runtime; отдельная установка .NET не требуется. Для релиза подготовлены установщик, portable, полный/delta пакеты, метаданные обновления, SHA256SUMS и отдельный архив диагностики. Исходные исполняемые файлы релиза 0.2.1 не заменяются.

После публикации 6 ноября пользователь подтвердил успешный запуск на затронутом компьютере с Windows 10, подключение по приглашению и скачивание файлов. Автообнаружение в первом тесте не использовалось успешно; колебания скорости через VPN требуют отдельных измерений. По просьбе пользователя сетевой транспорт оставлен без изменений. Это не подтверждает работу на всех старых сборках Windows. Полный путь применения обновления с GitHub в этой итерации не запускался; проверен локальный путь применения и перезапуска.
