# PeerFerry 0.1.0 — локальная проверка 6 ноября 2026

- Release-сборка решения: успешно, 0 предупреждений, 0 ошибок.
- xUnit: **15 пройдено, 0 ошибок, 0 пропущено**. Реальные loopback TCP/TLS/BitTorrent-соединения.
- Передача 16 МиБ с сохранением частичной загрузки, перезапуском и SHA-256: успешно.
- Получатель раздаёт третьему участнику после отключения исходного отправителя: успешно.
- Два одновременных торрент-соединения у получателя, ограничение приёма и итоговый SHA-256: успешно.
- Вложенная папка с кириллицей и пустым файлом, пауза, продолжение, удаление раздачи без удаления исходника: успешно.
- Недоступный/неверный первый endpoint и следующий рабочий адрес; исчезновение и восстановление выбранного binding: успешно.
- Чужой ключ группы, внешние трекеры, чужая группа в метаданных и опасные Windows-пути: отклонены.
- WPF smoke: запуск, публикация файла, генерация приглашения, отрисовка главного окна/передач/настроек, штатный выход: успешно; PNG просмотрены.
- Self-contained Windows x64: локально созданы Velopack Setup, Portable и update package; SHA-256 записаны в `dist/releases/SHA256SUMS.txt`.
- Настоящее обновление из локального feed: portable 0.1.0 скачала пакет 0.1.1, применила его и перезапустилась. Проверенный процесс сообщил package version `0.1.1`, assembly version `0.1.1.0`.
- NuGet advisory-проверка прямых и транзитивных зависимостей: известных уязвимых пакетов на момент проверки не обнаружено. Это не отдельный аудит безопасности.

Локальные профили, сертификаты, ключи, приглашения, изображения с адресами интерфейсов и тестовые feed остаются в игнорируемой `.work/`; они не публикуются. Доказательства локального прогона — `tests/PeerFerry.Tests/TestResults/local-release.trx`, `.work/ui-evidence-release/`, `.work/update-test-*/result.json`.

Не проверены: разные физические компьютеры, реальное обнаружение/переключение между ZeroTier и Radmin, пропускная способность VPN, многогигабайтные файлы, обновление с опубликованного GitHub Release. Следующий пользовательский шаг — [проверка с друзьями](TESTING.md).
