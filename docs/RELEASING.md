# Релизы и обновления

Публичные тестовые сборки публикуются в [GitHub Releases](https://github.com/rerit33/PeerFerry/releases). GitHub workflow на push/PR собирает и проверяет код. Ручной запуск Windows workflow дополнительно создаёт артефакты сборки, не публикуя Release автоматически.

1. Обновить версию по умолчанию в `Directory.Build.props` и `scripts/build.ps1`.
2. Выполнить `pwsh -File scripts/build.ps1 -Version 0.2.3`. Для нативного экрана установщика нужны MSVC x64 Build Tools и Windows SDK. Сборка проверяет PE-флаг `CET_COMPAT` итогового apphost: он должен быть выключен для совместимости с затронутыми ранними сборками Windows 10; ASLR/DEP должны сохраняться.
3. Проверить установщик/portable и сценарии из `TESTING.md`; сохранить SHA-256 и результаты.
4. Для следующего релиза, чтобы получить delta-пакет, предварительно скачать предыдущие пакеты в `dist/releases` средствами `dotnet vpk download github` или собрать полный пакет без delta.
5. Создать GitHub Release в `rerit33/PeerFerry`, приложить установщик, portable, `*-full.nupkg`, delta (если есть), `releases.win.json`, `assets.win.json`, `RELEASES`, `SHA256SUMS.txt`. Не загружать настройки/профили и `.work`.
6. Проверить публикацию feed и обновление предыдущей установленной версии. Приложение выбирает обычные опубликованные релизы; draft/prerelease не попадут в стабильный канал.

Velopack CLI и библиотека должны иметь одинаковую версию (сейчас 1.2.161). Сборки self-contained Windows x64. Для широкой публичной раздачи отдельно настроить Authenticode-подпись и защиту аккаунта GitHub. Встроенный GitHub access token не используется и не нужен для публичных релизов.

`vpk pack` включает обе стандартные локации ярлыков и иконку приложения. `build-installer.ps1` встраивает полученный Setup в небольшой Win32 bootstrapper: пользователь может снять любую галочку до установки. После успешной тихой установки убираются только невыбранные ярлыки этой установки; выбранные проверяются по целевому exe. При обновлении Velopack уважает отсутствие снятого ярлыка. Portable и nupkg не оборачиваются. Удаление приложения остаётся штатным Velopack.

Установщик поддерживает автоматизацию: `--silent --desktop-shortcut yes|no --start-menu-shortcut yes|no --installto <папка> --log <файл>`. Обычная установка запускает окно с двумя включёнными галочками. `--preview <PNG>` сохраняет снимок собственного окна и выходит без установки.
