# PeerFerry 0.2.0 — интерфейс, 6 ноября 2026

Перенесены пять утверждённых экранов из `design/approved`: светлая тема с зелёным акцентом, две вкладки, нижние сворачиваемые подробности и три раздела настроек. Друзья и журнал открываются отдельно. Добавлены общие векторные иконки и значок приложения.

Проверено локально на Windows:

- Сборка .NET Release: без предупреждений и ошибок.
- 15/15 тестов: настоящие TLS/BitTorrent-передачи, докачка и повторная раздача, два источника, общий лимит скорости, адаптеры, группы, безопасные пути. Дополнительно проверены предпросмотр без создания загрузки, точный объём подтверждённых частей, прогресс файлов и привязка входящих/исходящих соединений к именам.
- `scripts/test-ui.ps1`: три изолированных loopback-узла, реальные публикации и загрузка; каталог и содержимое до скачивания, два участника со скоростями, очередь и пауза, кнопки продолжения, поиск, сохранение выбора строки, сворачивание подробностей, окно 1000×680, три раздела настроек и приглашение. Для настроек проверены валидация, независимые лимиты и сохранение ручных галочек после смены режима, отсутствие изменения рабочего объекта до применения.
- Та же проверка UI выполнена для self-contained `dist/publish/PeerFerry.exe` и приложения из распакованного portable-пакета.
- `scripts/test-update.ps1`: настоящий portable-пакет 0.2.0 скачал локальный тестовый пакет 0.2.1, применил его и перезапустился. Итоговые package/assembly версии: `0.2.1` / `0.2.1.0`. Тестовая 0.2.1 не опубликована и не является пользовательской сборкой.
- PNG всех пяти экранов осмотрены; проверены также пустое состояние, компактное окно, каталог участников и приглашение. Результаты остаются в `.work/ui-test-*/screenshots/`; ключи тестовых групп не включены в исходники.

Собраны локально: `dist/releases/PeerFerry-win-Setup.exe`, `PeerFerry-win-Portable.zip`, `PeerFerry-0.2.0-full.nupkg`, контрольные суммы SHA-256. GitHub Releases не публиковались.

Проверка с друзьями через реальные ZeroTier/Radmin, скорость многогигабайтных передач и переключение маршрута между двумя VPN остаются пользовательской проверкой; локальные узлы этого не доказывают. Сценарий — в `TESTING.md`.
