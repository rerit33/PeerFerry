# PeerFerry 0.2.1 — 6 ноября 2026

- В установщик добавлен нативный экран с независимыми галочками «На рабочем столе» и «В меню Пуск». По умолчанию включены обе. Используется существующая иконка PeerFerry.
- Новые профили выбирают все активные IPv4-адаптеры. Явный выбор сохранённых профилей не меняется.
- Тестовый архив `dist/test-files/Notavirus.zip`: 1 073 760 288 байт, 39 записей, 1 ГиБ случайных данных плюс README/manifest. Проверены SHA-256 каждого файла и всего ZIP. Содержимое синтетическое, для передачи, без исполняемых программ и игровых модов. Архив и контрольные суммы остаются локально.

Проверка установщика использует отдельный пакет `PeerFerryInstallerTest`:

1. Все четыре комбинации ярлыков создают именно выбранные `.lnk`; цель и иконка ведут к установленному приложению.
2. Настоящее обновление установленного приложения 0.2.1 → 0.2.2 с перезапуском сохранило отключённый ярлык рабочего стола и существующий ярлык меню Пуск.
3. После каждого сценария штатное удаление убрало тестовые ярлыки. Рабочий профиль и установка PeerFerry не затрагивались.
4. Окно установщика осмотрено по PNG; исполняемый установщик не требует установленного .NET.

Сборки остаются локальными; GitHub Release не публикуется. Межкомпьютерную передачу и реальную скорость VPN нужно проверить с друзьями.
