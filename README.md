# PeerFerry

Бесплатное приложение для Windows: добавьте файл или папку, пригласите друзей и скачивайте друг у друга через LAN, ZeroTier или Radmin VPN. Встроенный BitTorrent обменивается проверенными частями файлов между участниками группы.

**Статус: 0.2.3, тестовая версия с привычными обозначениями KB, MB, GB и KB/s, MB/s.** Первый тест между компьютерами прошёл: подключение по приглашению и скачивание работают. Скорость через VPN требует отдельных измерений.

Готовые сборки: [PeerFerry 0.2.3 — установщик и portable](https://github.com/rerit33/PeerFerry/releases/tag/v0.2.3). В установленной или полной portable-версии обновление доступно через **Настройки → Основные → Проверить сейчас**. Если 0.2.1 вообще не запускается, скачайте новый установщик или полностью распакуйте новую portable-версию.

Если программа закрывается до появления окна, используйте [сборщик диагностики запуска](docs/TROUBLESHOOTING.md). Причина сбоя 0.2.1 на Windows 10 20H2 установлена по отчёту: ранний отказ .NET из-за CET. В 0.2.2 добавлена настройка совместимости; пользователь подтвердил успешный запуск и скачивание на затронутом компьютере.

## Возможности

- Публикация файлов и папок без создания копии или архива; drag and drop.
- Общий каталог, поиск, несколько источников одного файла.
- Две вкладки: «Доступные файлы» и «Передачи». Фильтры, действия в строках и сворачиваемые подробности снизу.
- Просмотр содержимого до скачивания; имена участников, доступная часть и скорости соединений.
- Приглашения `peerferry://join/…`, кнопка копирования и открытие ссылок в приложении.
- Выбор адаптеров: автоматически ZeroTier/Radmin, вручную или все активные.
- Для новых профилей по умолчанию выбраны все активные адаптеры, включая обычную LAN. Сохранённый выбор существующего профиля сохраняется.
- Установщик позволяет независимо выбрать ярлыки на рабочем столе и в меню «Пуск», с иконкой PeerFerry.
- Поиск участников через multicast/broadcast на выбранных интерфейсах; сохранённые адреса и обмен контактами внутри группы.
- Загрузка частями, проверка BitTorrent-хешей, докачка после перезапуска, пауза, очередь и лимиты скорости.
- Раздача полученных частей и файлов; исходный отправитель может уйти, если нужные части остались у других участников.
- Сворачивание в трей. Для полного выхода используйте меню значка в трее.
- Проверка и загрузка обновлений из GitHub Releases через Velopack; применение по кнопке с сохранением передач.

## Как попробовать вдвоём

1. Запустите `PeerFerry-win-Setup.exe`, выберите нужные ярлыки и нажмите «Установить». Либо распакуйте **весь** `PeerFerry-win-Portable.zip` и запустите корневой `PeerFerry.exe`.
2. Включите одну и ту же VPN-сеть на обоих компьютерах.
3. В **Настройки → Основные** задайте имя и папку загрузок. Новый профиль сразу использует все активные адаптеры. В разделе **Сеть** можно выбрать только нужные адаптеры вручную или автоматический выбор ZeroTier/Radmin.
4. Разрешите входящие подключения PeerFerry в брандмауэре для выбранной сети: по умолчанию TCP 45831 и UDP 45832 для поиска. Отключать брандмауэр целиком не требуется.
5. На первом компьютере нажмите **Пригласить**, отправьте ссылку другу. Друг открывает стрелку рядом с кнопкой «Пригласить» → **Присоединиться по приглашению** и вставляет ссылку. Обоим нужна достижимость адресов через общую сеть.
6. Добавьте файл или папку (папка — через стрелку у «Добавить файлы» либо перетаскиванием). Друг откроет **Доступные файлы** и нажмёт **Скачать**. Загрузка сохранится в выбранную папку без повторного запроса и появится на вкладке **Передачи**.
7. При необходимости разрешите приложению работать в трее: закрытие окна по умолчанию продолжает раздачи.

Настройки, ключи группы, сертификат устройства и прогресс хранятся в `%LOCALAPPDATA%\PeerFerry`. Публикации не копируются. Удаление из списка прекращает раздачу и сохраняет файлы на диске. Каждая загрузка получает отдельную папку, существующие пользовательские файлы не перезаписываются.

## Модель доступа и сеть

Приглашение содержит секрет группы. Любой обладатель приглашения может присоединиться и получить доступ к опубликованным раздачам. Не публикуйте приглашения открыто. В 0.2.3 нет индивидуального отзыва доступа: для нового состава участников создайте новую группу через отдельный профиль или присоединитесь к новому приглашению.

Внешний транспорт: TLS 1.2/1.3, взаимное подтверждение владения ключом группы через HMAC-SHA256 и привязка доказательства к сертификатам обоих устройств и случайному вызову. Известные адреса проверяются по отпечатку сертификата. Самоподписанный сертификат не добавляется в системные доверенные центры.

BitTorrent-движок MonoTorrent слушает **только loopback**. Внешние подключения проходят через аутентифицированный шлюз PeerFerry. Отключены DHT, публичные трекеры, PEX, Web Seeds, автоматическое открытие портов и штатный LAN-поиск движка. Приватность задаётся транспортом и членством группы, а не флагом BEP-27: этот флаг препятствует ручному добавлению проверенных peers в MonoTorrent 3.0.2. Метаданные привязаны к группе и не принимают внешние источники.

Исходящие TCP-сокеты привязаны к выбранному локальному IPv4 и, на Windows, к индексу интерфейса (`IP_UNICAST_IF`). Смена доступных адресов закрывает старые туннели и восстанавливает связь. Недоступный выбранный адаптер не заменяется произвольным рабочим VPN. Автообнаружение не перебирает IP-диапазоны; если multicast заблокирован, используйте приглашение. Сведения об имени и адресах в discovery-пакете доступны наблюдателям выбранной сети, содержимое файлов идёт по TLS.

GitHub используется только для исходников и обновлений. Пользовательские файлы и ключи туда не отправляются. У приложения нет серверной телеметрии. VPN-провайдер всё ещё может использовать свои ретрансляторы; пропускная способность ограничена реальным каналом и маршрутом VPN.

## Ограничения первой версии

- Windows x64, IPv4, одна активная группа. Переход между группами сохраняет файлы и записи передач предыдущей группы, но останавливает её обмен.
- До 128 известных участников, 1 000 активных записей каталога на участника и 20 000 файлов в раздаче.
- Символические ссылки и junctions в раздачах/папке загрузок не поддерживаются. Опубликованный исходник не следует менять; обнаружив изменение, PeerFerry приостанавливает раздачу.
- Скорость через ZeroTier/Radmin, массовые раздачи и многогигабайтные файлы ещё не измерялись на разных компьютерах.
- Сборки пока без Authenticode-подписи. Механизм обновления доверяет указанному GitHub-репозиторию и HTTPS; аккаунт публикации должен быть защищён.
- Релизы содержат установщик, portable-архив и файлы обновления. Запуск отдельных файлов из папки `dist/publish` не заменяет установленную/полную portable-версию для обновлений.

## Разработка

Для разработки требуется Windows и .NET SDK 10; для сборки установщика — MSVC x64 Build Tools и Windows SDK (Visual Studio / Build Tools с компонентом C++). Приложение на C# / WPF; файлы передаёт MonoTorrent 3.0.2, упаковка и обновления — Velopack 1.2.161. Перед стандартной установкой открывается небольшой нативный экран выбора ярлыков. Self-contained-сборка содержит .NET: друзьям не нужно устанавливать SDK/runtime.

```powershell
dotnet restore PeerFerry.sln
dotnet test tests/PeerFerry.Tests -c Release
dotnet run --project src/PeerFerry.App
pwsh -File scripts/build.ps1
```

Изолированный профиль для параллельных экземпляров:

```powershell
dotnet run --project src/PeerFerry.App -- --data-dir .work/profile-a
```

Результат сборки: `dist/releases/PeerFerry-win-Setup.exe` и `dist/releases/PeerFerry-win-Portable.zip`. Не переносите отдельно исполняемый файл portable-пакета: ему нужны `current/`, `Update.exe` и `.portable`.

Сценарии проверки: [TESTING.md](docs/TESTING.md). Устройство протокола: [ARCHITECTURE.md](docs/ARCHITECTURE.md). Подготовка релизов: [RELEASING.md](docs/RELEASING.md).
